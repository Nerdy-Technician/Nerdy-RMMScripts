# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/Nerdy-Technician/Nerdy-RMMScripts/security/advisories/new)

Include the affected script, what the issue is, and steps to reproduce. You'll get a response as soon as possible, and credit once a fix is out if you'd like it.

## Scope

This repository contains RMM scripts for Windows (PowerShell/Batch) and Linux (Bash). Reports about a script that could expose credentials, weaken a system's security, or be abused when run by an RMM agent are especially welcome.

Always review a script before running it in your environment.
